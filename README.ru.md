## Скачать игру

- **Windows 10 или 11:** [Страница релизов](https://github.com/og-cz/taga-komando/releases)
  - `TagaKomando-Setup-<version>.exe`: установщик (ярлык в меню «Пуск», удаление)
  - `TagaKomando-Portable-<version>.exe`: один файл, без установки, запускается откуда угодно
- **Предупреждение «Система Windows защитила ваш компьютер»:** приложение пока не подписано. Нажмите **Подробнее → Выполнить в любом случае**.
- **Ошибки и предложения:** https://github.com/og-cz/taga-komando/issues

## 获取游戏

- **Windows 10 或 11:** [发布页面](https://github.com/og-cz/taga-komando/releases)
  - `TagaKomando-Setup-<version>.exe`: 安装程序(开始菜单快捷方式、卸载程序)
  - `TagaKomando-Portable-<version>.exe`: 单个文件,无需安装,可在任意位置运行
- **“Windows 已保护你的电脑”警告:** 该应用尚未进行代码签名。请点击 **更多信息 → 仍要运行**。
- **问题反馈 / 建议:** https://github.com/og-cz/taga-komando/issues

## 게임 받기

- **Windows 10 또는 11:** [릴리스 페이지](https://github.com/og-cz/taga-komando/releases)
  - `TagaKomando-Setup-<version>.exe`: 설치 프로그램(시작 메뉴 바로 가기, 제거 프로그램 포함)
  - `TagaKomando-Portable-<version>.exe`: 단일 파일, 설치 불필요, 어디서나 실행
- **"Windows의 PC 보호" 경고:** 앱이 아직 코드 서명되지 않았습니다. **추가 정보 → 실행**을 클릭하세요.
- **버그 신고 / 제안:** https://github.com/og-cz/taga-komando/issues

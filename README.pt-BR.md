## Baixe o jogo

- **Windows 10 ou 11:** [Página de versões](https://github.com/og-cz/taga-komando/releases)
  - `TagaKomando-Setup-<version>.exe`: instalador (atalho no menu Iniciar, desinstalador)
  - `TagaKomando-Portable-<version>.exe`: arquivo único, sem instalação, roda de qualquer lugar
- **Aviso "O Windows protegeu o computador":** o aplicativo ainda não é assinado. Clique em **Mais informações → Executar assim mesmo**.
- **Bugs / sugestões:** https://github.com/og-cz/taga-komando/issues

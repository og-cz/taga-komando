## Spiel herunterladen

- **Windows 10 oder 11:** [Release-Seite](https://github.com/og-cz/taga-komando/releases)
  - `TagaKomando-Setup-<version>.exe`: Installer (Startmenü-Verknüpfung, Deinstallation)
  - `TagaKomando-Portable-<version>.exe`: eine einzige Datei, keine Installation, läuft überall
- **Warnung „Der Computer wurde durch Windows geschützt“:** Die App ist noch nicht signiert. Auf **Weitere Informationen → Trotzdem ausführen** klicken.
- **Fehler / Vorschläge:** https://github.com/og-cz/taga-komando/issues

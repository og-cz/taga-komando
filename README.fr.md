## Obtenir le jeu

- **Windows 10 ou 11:** [Page des versions](https://github.com/og-cz/taga-komando/releases)
  - `TagaKomando-Setup-<version>.exe`: installateur (raccourci dans le menu Démarrer, désinstallateur)
  - `TagaKomando-Portable-<version>.exe`: un seul fichier, sans installation, se lance de n'importe où
- **Avertissement « Windows a protégé votre ordinateur »:** l'application n'est pas encore signée. Cliquez sur **Informations complémentaires → Exécuter quand même**.
- **Bugs / suggestions:** https://github.com/og-cz/taga-komando/issues

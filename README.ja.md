## ダウンロード

- **Windows 10 / 11:** [リリースページ](https://github.com/og-cz/taga-komando/releases)
  - `TagaKomando-Setup-<version>.exe`: インストーラー(スタートメニューのショートカット、アンインストーラー付き)
  - `TagaKomando-Portable-<version>.exe`: 単一ファイル、インストール不要、どこからでも起動可能
- **「WindowsによってPCが保護されました」という警告:** アプリはまだコード署名されていません。**詳細情報 → 実行** をクリックしてください。
- **バグ報告・提案:** https://github.com/og-cz/taga-komando/issues
